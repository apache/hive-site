# Apache Hive : DROP TABLE Statement

DROP TABLE statement drops a table.

**Syntax**:

```
DROP TABLE [IF EXISTS] table_name 
```

**Compatibility:** Oracle, Microsoft SQL Server, IBM DB2, Teradata, PostgreSQL, MySQL, Hive

**Version**: HPL/SQL 0.3
