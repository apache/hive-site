# Apache Hive : SYSDATE Function

SYSDATE function returns the current date and time (year, month, day, hour, minute and seconds).

**Syntax**:

```
SYSDATE
```

**Return Type:**

TIMESTAMP

**Example**:

Get the current and date and time:

```
SYSDATE
--
2015-03-03 11:06:31
```

**Compatibility**: Oracle

**Version:** HPL/SQL 0.3
