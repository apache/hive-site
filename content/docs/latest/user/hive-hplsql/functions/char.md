# Apache Hive : CHAR Function - PL/HQL Reference

CHAR function converts a number to string.

**Syntax**:

```
CHAR(num_expression); 
```

**Return Type:**

STRING

**Example 1:**

```
CHAR(1000); 
--
1000
```

**Compatibility**: IBM DB2

**Version**: PL/HQL 0.03
