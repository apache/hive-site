# Apache Hive : CURRENT_DATE Function

CURRENT_DATE function return the current date (year, month and day).

**Syntax**:

```
CURRENT_DATE | CURRENT DATE 
```

**Return Type:**

DATE

**Compatibility**: IBM DB2, Teradata, MySQL.

**Version:** HPL/SQL 0.01
